## 📝 论文概述

本文基于 **GB 50010-2010《混凝土结构设计规范》**，使用 Python 实现了三种钢筋混凝土截面的**正截面受弯承载力验算（复核）**程序。与"设计"程序（已知弯矩求配筋）不同，复核程序的输入是**已知配筋面积 As**，输出是**承载力 Mu 与安全判定**。

三种截面类型：**单筋矩形截面**、**双筋矩形截面**、**T 形截面**。

### 各复核脚本说明

| 脚本 | 输入 | 输出 | 核心判据 |
|------|------|------|---------|
| `单筋复核.py` | b, h, M, fc, fy, ft, As, c, α₁, ξb, D, d | Mu, 安全裕度, ✅/❌ | ξ = fy·As/(α₁·fc·b·h₀)；Mu = α₁·fc·b·h₀²·ξ·(1-0.5ξ) |
| `双筋复核.py` | 同上 + fy', n, d, n', d' | Mu, 安全判定 | x = (fy·As-fy'·As')/(α₁·fc·b)；分段计算 Mu |
| `T型截面复核.py` | 同上 + bf, hf | Mu, 截面类型, 安全判定 | fy·As ≤ α₁·fc·bf·hf → 第一类；否则第二类分解 |

## 🧮 复核计算流程

### 单筋矩形截面

```
输入截面参数 + 已知 As
        ↓
计算 a → h₀
        ↓
ξ = fy·As / (α₁·fc·b·h₀)
        ↓
判断：ξ > ξb？→ 超筋，取 ξ = ξb
        ↓
配筋率校核：ρ ≥ ρ_min？
        ↓
Mu = α₁·fc·b·h₀²·ξ·(1-0.5ξ)
        ↓
比较 Mu ≥ M → ✅ 安全 / ❌ 不安全
```

### 双筋矩形截面

```
已知 As, As'（由 n×A_single 算得）
        ↓
x = (fy·As - fy'·As') / (α₁·fc·b)
        ↓
┌─ x < 2a'：Mu = fy·As·(h₀-a')    （偏安全）
├─ 2a' ≤ x ≤ ξb·h₀：Mu = α₁·fc·b·x·(h₀-x/2) + fy'·As'·(h₀-a')
└─ x > ξb·h₀：取 ξ=ξb 计算 Mu    （超筋处理）
        ↓
比较 Mu ≥ M
```

### T 形截面

```
已知 As
        ↓
fy·As ≤ α₁·fc·bf·hf？
  ├─ 是 → 第一类 T 形：按 bf 宽矩形截面计算 ξ, Mu
  └─ 否 → 第二类 T 形：
         As₁ = α₁·fc·(bf-b)·hf/fy  （翼缘挑出部分）
         As₂ = As - As₁             （腹板部分）
         Mu₁ = fy·As₁·(h₀-hf/2)
         Mu₂ = α₁·fc·b·h₀²·ξ·(1-0.5ξ)  （ξ≤ξb，否则取ξb）
         Mu = Mu₁ + Mu₂
        ↓
比较 Mu ≥ M
```

## 🔄 设计 vs 复核 对比

| 维度 | 设计（另一篇论文） | 复核（本篇） |
|------|------------------|-------------|
| 已知量 | 弯矩设计值 M | 配筋面积 As |
| 求解目标 | 钢筋面积 As, As' | 承载力 Mu |
| 核心公式 | αs → ξ → As | As → ξ → Mu |
| 应用场景 | 新建工程设计 | 既有结构安全性评估 |
| 典型问题 | "承受 150kN·m 需要多少钢筋？" | "现有 4Φ20 能不能抗住 150kN·m？" |

## 💡 代码特色

- **安全输入校验：** `input_float()` 循环读取直到合法值
- **分情形处理：** 双筋截面按 x 位置分三段计算；T 形按类型分支
- **超筋降级：** 当 ξ > ξb 时偏安全取 ξb 计算（并给出警告）
- **详细输出：** 每一步中间量（ξ, x, Mu分量）均打印，便于追溯
