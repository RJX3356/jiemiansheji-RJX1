## 📝 论文概述

本文基于 **GB 50010-2010《混凝土结构设计规范》**，使用 Python 实现了三种钢筋混凝土矩形截面的**正截面受弯配筋设计**计算程序。程序采用**面向过程 + 面向对象混合**架构，核心计算通过 `Section` 类管理截面参数，并配备安全输入校验函数。

三种截面类型：**单筋矩形截面**、**双筋矩形截面**、**T 形截面**。

### 核心设计脚本

| 脚本 | 输入 | 输出 | 核心逻辑 |
|------|------|------|---------|
| `单筋设计.py` | b, h, M, fc, fy, ft, c, α₁, ξb, D, d | As, 配筋率, 选筋, 排列宽度 | αs → ξ → As → 校核ρ_min → 选筋迭代 |
| `单筋设计method2.py` | 同上 | As（双方法互验）| As₁ = ξ·b·h₀·α₁·fc/fy, As₂ = M/[fy·h₀·(1-0.5ξ)] |
| `双筋设计.py` | 同上 + fy' | As, As' | 模式1：已知As'求As；模式2：ξ=ξb同时设计 |
| `T型截面设计.py` | 同上 + bf, hf | As | M ≤ Mf → 第一类按bf×h矩形算；否则第二类分解 |

## 🧮 设计计算原理

```
输入: b, h, M, fc, fy, ft, c, α₁, ξb, D, d
                ↓
    [计算几何参数]  a = c + D + d(+25/2),  h₀ = h - a
                ↓
    [截面抵抗矩系数]  αs = M / (α₁·fc·b·h₀²)
                ↓
    [超筋判别]  αs > αs_max = ξb·(1-0.5ξb) ? → 退出/加大截面
                ↓
    [相对受压区高度]  ξ = 1 - √(1-2αs)
                ↓
    [受拉钢筋面积]  As = ξ·b·h₀·α₁·fc / fy
                ↓
    [最小配筋率]  ρ ≥ max(0.45·ft/fy·h/h₀, 0.002·h/h₀)
                ↓
    [选筋 + 排列验算]  n·d + (n-1)·25 + 2(c+D) ≤ b ?
```

### 双筋截面特殊处理

| 模式 | 条件 | 方法 |
|------|------|------|
| 模式1（As'已知）| 已配受压钢筋 | M_c = M - fy'·As'·(h₀-a'), 按M_c求拉筋 |
| 模式2（As'未知）| 从头设计 | 取ξ=ξb，As' = (M-M_single_max)/[fy'·(h₀-a')] |

### T 形截面分类

| 截面类型 | 判定条件 | 计算方法 |
|---------|---------|---------|
| 第一类（中和轴在翼缘内）| M ≤ α₁·fc·bf·hf·(h₀-hf/2) | 按 bf×h 矩形截面计算 |
| 第二类（中和轴进入腹板）| M > 上述值 | 翼缘挑出部分 + 腹板分别计算 |

## 💡 代码特色

- **面向对象架构：** `Section` 类统一管理截面所有参数与计算中间量
- **安全输入：** `input_float()` / `input_int()` 带类型校验和范围约束
- **纯函数计算：** `calc_geometry()` / `calc_xi()` / `calc_As()` 不产生副作用
- **智能迭代：** 排列宽度不满足时自动提示调整，无需重新运行
- **详细中间输出：** 每步计算结果透明可查，便于论文撰写和调试
